# ApexPlanet Internship - Task 1

## Data Immersion & Data Wrangling

### Objective
The objective of this task is to understand the dataset, identify data quality issues, clean the data, and prepare it for analysis.

## Dataset Information

- Total Records: 1000
- Total Columns: 12

### Columns

1. Order_ID
2. Order_Date
3. Customer_ID
4. Customer_Name
5. Age
6. Gender
7. City
8. Product
9. Category
10. Quantity
11. Unit_Price
12. Total_Sales

## Data Cleaning Performed

- Loaded the dataset using Pandas
- Checked dataset structure
- Displayed summary statistics
- Identified missing values
- Filled missing values in Age using Mean
- Filled missing values in City using Mode
- Checked duplicate records
- Converted Order_Date to DateTime format
- Saved the cleaned dataset
